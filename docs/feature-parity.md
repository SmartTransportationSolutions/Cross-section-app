## Deviations and reductions (audit history)

- **2026-10-03 — AUTH-OIDC-01:** Upstream offered Google, Facebook and Twitter sign-in through Auth0 connections. STS Street implements federated sign-in generically (any OIDC provider) but no provider is configured; social sign-in is BLOCKED until STS supplies provider credentials. No reduction of the capability itself; configuration pending.
- **2026-10-03 — MEMB-BILLING-01:** Upstream membership activation was manual (OpenCollective/Patreon e-mail matching). STS Street replaces it with administrator-granted roles. Self-service payment is a business decision; recorded as BLOCKED, not excluded.
- **2026-10-03 — DEP-SERVICES-01:** Intentional removals of operator-specific integrations: Coil/Web Monetization (discontinued upstream 2023), Patreon OAuth linking (granted no roles upstream), Stripe stub (dead code), Userback feedback widget, New Relic, hard-coded Sentry DSN, Cloudflare Insights, Buttondown newsletter POST from the browser (replaced by first-party list), /map redirect to an external upstream viewer, Store and sponsorship links.
- **2026-10-03 — AUTHZ-USER-01:** Deliberate security fixes beyond parity: PATCH /users/:id ownership check, DELETE /users/:id now deletes, GET /users admin check hardened, POST /users (public account creation from Auth0 payloads) removed, server-side enforcement of premium export options.
- **2026-10-03 — PAGES-DEPLOY-01:** STS chose GitHub Pages hosting with GitHub as the database ("Use github pages, and simple github dbs"). Added a static edition (docs/architecture.md §7). Capabilities that need a server (email/password and OIDC sign-in, newsletter, surveys, server image renderer, remixes CSV, global gallery) remain implemented in the server edition and are unavailable in the Pages edition; their rows are not removed or weakened. Pages-specific rows added (PAGES-*).
- **2026-10-03 — QA-AUDIT:** Independent QA audit (scratchpad report, summarized in docs/acceptance-report.md) found VERIFIED rows whose cited evidence did not exist or did not test the claim. Those rows were downgraded to IMPLEMENTED_UNVERIFIED with the reason in notes (no requirement removed). The E2E evidence string now comes from a single full 10/10 run with its log committed. The DB-backed identity tests now run (locally and in CI) and replace the non-existent "J1b" citation.
